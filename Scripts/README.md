# Scripts

This folder contains the available code used for SNP selection, genetic model development and fusion model development in this project.

The scripts include code for identifying candidate SNPs, developing machine learning models based on genetic data and building fusion models that combine genetic risk information with demographic and serological variables.

The code is provided to make the analytical workflow more transparent and reproducible. However, the scripts retrieve data from dataframes containing patient information, which cannot be shared due to confidentiality restrictions.
